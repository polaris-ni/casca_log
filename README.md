# Casca Log
Casca Log是一个纯C语言的日志框架，希望成为一个简单易用、扩展性好、功能丰富、性能优秀的跨平台的日志库。
## 框架简介
Casca Log的框架结构如下，划分为过滤器（Filter）、格式化器（Formatter）、分发器（Dispatcher）、聚合器（Collector）、记录器（Recorder）等模块。调用者（Caller）在打印日志时，首先会生成`clog_item_t`，包含日志的模块、目的地、级别、时间、内容等信息，然后调用`前向过滤器`进行过滤。经过`前向过滤器`后，会使用`格式化器`对日志进行格式化，然后调用`分发器`对日志进行分发。如果使用`同步分发器`，则会直接调用`记录器`进行记录。如果使用`异步分发器`，则会将日志发送到其他地方（队列、共享内存、字符设备等），由`聚合器`收集完成后调用`记录器`进行记录。`记录器`可以将日志写入文件、数据库、控制台等地方。`同步过滤器`适用于快速打印日志、较少`记录器`、记录器不耗时的场景。如果日志输出场景比较复杂，则使用`异步过滤器`，减少性能影响。
